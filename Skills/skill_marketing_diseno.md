# SKILL: DISEÑO DE MARKETING VISUAL Y ASSETS PARA REDES SOCIALES

## OBJETIVO
Generar estructuras, plantillas y código SVG/HTML5 para piezas visuales de alta conversión en Instagram, TikTok y Facebook, ajustadas al tono del cliente.

## 1. FORMATOS Y DIMENSIONES
- **Historias / Reels / TikTok (9:16):** 1080 x 1920 px.
- **Posts Cuadrados (1:1):** 1080 x 1080 px.
- **Posts Verticales / Carruseles (4:5):** 1080 x 1350 px.
- **Banners Web / Hero Banners (16:9):** 1920 x 1080 px.

## 2. GUÍAS Y PLANTILLAS DINÁMICAS (SVG / HTML5)
- **Generación de código SVG/HTML:** Crear layouts adaptables con la paleta HEX del cliente, tipografías llamativas y contenedores para imágenes/mockups.
- **Composición Visual:**
  - Uso de contrastes altos para destacar ofertas o productos clave.
  - Margen de seguridad del 10% en bordes para evitar superposición con botones de redes sociales.
  - Etiquetas de precio tipo "Badge", stickers de ubicación ("Querétaro") e indicadores de "Desliza" para carruseles.
