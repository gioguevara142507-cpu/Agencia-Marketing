# SKILL: DESARROLLO WEB INTERACTIVO CON ANIMACIONES Y UI/UX PREMIUM

## OBJETIVO
Construir sitios web e-commerce y landing pages profesionales, ultra atrayentes y responsivos con animaciones avanzadas, microinteracciones y estándares modernos de UI/UX.

## 1. STACK TECNOLÓGICO DE ANIMACIÓN Y ESTILOS
- **Estilos:** Tailwind CSS (clases de utilidad, diseño responsivo móvil-primero, gradientes modernos, glassmorphism).
- **Animaciones y Efectos:**
  - **Framer Motion / GSAP / AOS (Animate On Scroll):** Animaciones de entrada al hacer scroll, efectos parallax y revelado suave de texto/imágenes.
  - **Hover Effects:** Transiciones suaves (transition-all duration-300), escalado de imágenes en productos (hover:scale-105), sombras dinámicas y botones con efecto "glow".
  - **Canvas / Three.js / CSS Keyframes:** Fondos interactivos con partículas, sombras borrosas en movimiento (blur blobs) y gradientes dinámicos.

## 2. COMPONENTES CLAVE PARA PAGINAS WEB Y E-COMMERCE
- **Hero Section Impactante:** Titular dinámico con efecto tipográfico animado, fondo con video/canvas interactivo o carrusel 3D de productos, e indicadores de scroll.
- **Catálogo & Fichas de Productos:** Tarjetas con vista rápida (Quick View), animaciones al agregar al carrito (efecto volador/flotante), selector de variantes interactivo y galería de imágenes con zoom.
- **Carrito Flotante (Slide-over Cart):** Drawer lateral responsivo con contador animado, barra de progreso para envío gratis y checkout rápido.
- **Microinteracciones UI/UX:** Notificaciones tipo "Toast" al agregar productos, acordiones desplegables para FAQ/detalles, indicadores de carga (spinners) y loaders personalizados.

## 3. CIBERSEGURIDAD Y PASARELAS DE PAGO
- Integración limpia con **Shopify Headless API**, **Stripe Elements** o **Mercado Pago Checkout Pro**.
- Certificación SSL, formularios con validación en tiempo real y cumplimiento de seguridad PCI-DSS sin almacenar datos sensibles localmente.
